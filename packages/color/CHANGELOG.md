# @driftime/sanity-plugin-color

## 0.1.0

### Minor Changes

- Initial release. A color field for Sanity Studio that offers a palette, colors found in an image, or a custom value, pairs each background with text, and measures every pairing against WCAG 2.2 as it is chosen. Ships a `./render` entry that resolves a stored color to hex, RGB, and OKLCH for a consumer's site. Requires Sanity Studio 6.10 or later.
